Contributing
=============

Thank you for your interest in contributing! To make contributions easy to review and accept, please follow these guidelines:

- Fork the repository and create a branch for your change.
- Format Python code with black and isort.
- Run linters (flake8) and tests before opening a PR.
- Open a clear pull request describing the change and why it is needed.

If you're unsure where to start, open an issue with a description and we can help triage.
